## 📌 Projetos em Destaque

### 🎯 [Bingo Unimed — Sistema Web de Integração Corporativa](https://github.com/cristiermc/bingo-unimed)
Aplicação web interativa desenvolvida para engajar colaboradores de múltiplos setores e estabelecimentos em eventos corporativos da Unimed Tubarão.

- **O Desafio:** Integrar o sorteio físico com globo a uma transmissão remota via MS Teams, garantindo acompanhamento síncrono e sem ruídos para todas as unidades descentralizadas.
- **A Solução:** Plataforma dinâmica com Landing Page de autenticação, Painel do Jogador (grade de 1 a 99, mural de fotos, histórico) e Painel ADM (controle de rodadas e validação).
- **Tecnologias & Conceitos:** Arquitetura Web, Gestão de Estado, UX/UI e Vibe Coding.

🔗 **[Acessar Repositório do Bingo Unimed](https://github.com/cristiermc/bingo-unimed)**

### 🕹️ [Pokédex Web App](https://github.com/cristiermc/pokedex)
Aplicação interativa para consulta de Pokémons desenvolvida para praticar consumo de serviços web e manipulação de dados em tempo real.

- **O Desafio & Aprendizado:** Implementar requisições assíncronas a uma API REST externa (PokéAPI), tratar estados de carregamento e construir uma busca/filtragem fluida.
- **Funcionalidades:** Busca por nome/ID, listagem dinâmica, exibição de estatísticas/tipos e design responsivo.
- **Tecnologias & Conceitos:** JavaScript / TypeScript, HTML5, CSS3, APIs RESTful (PokéAPI) e Async/Await.

🔗 **[Acessar Repositório da Pokédex]([https://github.com/cristiermc/pokedex](https://github.com/cristiermc/pokedex-by-cristec.git))**
